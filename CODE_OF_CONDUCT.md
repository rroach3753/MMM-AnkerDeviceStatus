# Code of Conduct

## Our standards

Everyone participating in this project is expected to be respectful,
constructive, and considerate. Harassment, discrimination, personal attacks,
and the sharing of another person's private information are not acceptable.

## Reporting

Report conduct concerns privately to the project maintainers through GitHub.
Please include enough context to understand and investigate the concern.
Maintainers will review reports as promptly and confidentially as practical.

## Scope

These standards apply in project spaces, including issues, pull requests, and
other project-related communication.
